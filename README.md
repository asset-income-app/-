# 不良资产行业导航网站

一个专业的不良资产行业导航网站，汇集不良资产处置、资产管理、债权转让等行业资源。

## 📊 项目数据

- **导航链接**：60+ 个
- **分类数量**：11 个
- **技术栈**：Vue 3 + Vite
- **部署方式**：Netlify（免费）

## ✨ 功能特点

### 核心功能
- 🎯 **分类导航**：11大分类，涵盖政府监管、全国性AMC、地方AMC、交易平台、银行机构、法律司法、信息平台、拍卖机构、行业协会、研究资讯、专业服务机构
- 🔍 **智能搜索**：支持按名称、描述、网址实时搜索
- 🏷️ **标签筛选**：点击标签快速筛选相关网站，支持多维度筛选
- 📱 **响应式设计**：完美适配桌面端和移动端

### 交互增强
- 🖼️ **网站图标**：自动获取并显示每个网站的favicon
- 📌 **粘性导航**：顶部导航栏滚动时固定，方便随时搜索
- ⬆️ **回到顶部**：一键返回页面顶部，带平滑滚动动画
- 📂 **分类折叠**：点击分类标题可展开/收起，节省页面空间

### 设计特点
- 🎨 渐变紫色主题，专业美观
- 💳 卡片式布局，清晰易读
- ✨ 悬停动画效果，交互友好
- 🌈 Emoji图标，视觉丰富

## 🚀 快速开始

### 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

开发服务器地址：http://localhost:5173/

### 部署到Netlify

#### 方法一：拖拽部署（最简单）

1. 构建项目：`npm run build`
2. 访问 https://app.netlify.com/drop
3. 将 `dist` 文件夹拖到页面虚线框
4. 等待部署完成，获得临时网址

#### 方法二：GitHub + Netlify（推荐）

1. 将代码推送到GitHub仓库
2. 登录 https://www.netlify.com/
3. 点击 "New site from Git"
4. 选择你的GitHub仓库
5. 构建命令会自动检测，点击 "Deploy site"

#### 方法三：Netlify CLI

```bash
# 安装Netlify CLI
npm install -g netlify-cli

# 登录Netlify
netlify login

# 初始化项目
netlify init

# 部署
netlify deploy --prod
```

## 🔧 自定义导航

编辑 `src/data/navigation.js` 文件即可添加或修改导航链接：

```javascript
export const navigationData = [
  {
    id: 1,
    name: '分类名称',
    icon: '🏛️',  // emoji图标
    links: [
      {
        name: '链接名称',
        url: 'https://example.com',
        description: '链接描述',
        tags: ['标签1', '标签2']
      }
    ]
  }
]
```

修改后需要重新构建：`npm run build`

## 💰 变现思路

### 高潜力方向

1. **广告位/推荐位**
   - 不良资产处置机构、律所、评估公司愿意为曝光付费
   - 首页推荐位：2000-5000元/月

2. **信息撮合/线索导流**
   - 收集买卖双方需求，对接成交后抽佣
   - 不良资产单笔金额大，1%佣金可观

3. **付费收录/会员**
   - 高级会员可展示更多信息（logo、联系方式、案例等）
   - 价格：1000-3000元/年

### 中等潜力

4. **行业资讯/付费社群**
   - 建立不良资产微信社群，付费入群
   - 价格：299-999元/年

5. **培训/课程**
   - 不良资产处置实务培训
   - 价格：线上课 999-2999元，线下课 5000+元

6. **数据服务**
   - 整理不良资产处置数据，做行业报告
   - 价格：500-2000元/份

### 建议路径

```
第一步（0-6个月）：免费运营，积累流量和用户
    ↓
第二步（6-12个月）：推出付费收录 + 广告位
    ↓
第三步（12-18个月）：建立付费社群 + 信息撮合
    ↓
第四步（18个月+）：培训课程 + 数据服务 + 行业峰会
```
